FIREMAN BURGER — Offline Local Website
================================

Open index.html directly in a browser. All website assets, stylesheets, fonts, JavaScript libraries,
images, SVGs, and the Lottie JSON included in the supplied Webflow export have been redirected to local files.

Note: the supplied archive contains only the homepage (index.html). Internal routes such as /about, /menu,
and /contact were not included as separate HTML pages in the archive, so those pages cannot be recreated
from the supplied files alone. External social/template links remain external because they are navigation
destinations, not site assets.
